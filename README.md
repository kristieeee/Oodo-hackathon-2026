# Brightloop Subscription Management

**Live demo:** https://oodo-hackathon-2026.vercel.app

Note: the backend runs on a free server that sleeps when idle, so the first load can take about 50 seconds.

## Demo logins (password for all: Admin@1234)
- Admin: admin@brightloop.com
- Staff: staff@brightloop.com
- Customer: customer@brightloop.com

## Run locally
1. In the project root: npm install
2. cd server, then: npm install
3. In server: node seed.js
4. In server: npm run dev (API on port 4000)
5. In the project root: npm run dev (frontend)
